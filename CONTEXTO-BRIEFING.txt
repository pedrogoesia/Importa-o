--------------------------------------------------------------------------------
PAPEL E OBJETIVO
--------------------------------------------------------------------------------
Você é um engenheiro front-end sênior e product designer. Construir a base visual
e estrutural de um sistema web de IA para importadoras.

O objetivo agora NÃO é criar backend real. O foco é criar um front-end navegável,
profissional, limpo, moderno e preparado para depois conectar com APIs, banco de
dados, integrações bancárias, Siscomex, Siscarga, emissão de boletos e agentes de IA.


--------------------------------------------------------------------------------
CONTEXTO DO PRODUTO
--------------------------------------------------------------------------------
Estamos criando um sistema operacional com IA para importadoras que hoje trabalham
com muitas informações espalhadas em Google Drive, planilhas, WhatsApp, e-mail,
Siscomex, Siscarga, controle manual de boletos, contas a pagar e processos fiscais
separados.

O produto deve parecer um ERP moderno + sistema operacional de IA para importadoras.

A lógica central é:
Empresa/CNPJ → Processo de importação → Documentos → Atualizações de carga →
Financeiro → Fiscal → Relatórios e alertas.

Tudo deve nascer de um processo de importação.

Cada processo representa uma carga/operação de importação. A numeração que diferencia
cada processo pode ser o número do BL/conhecimento de embarque, inserido manualmente.

5. ATUALIZAÇÕES DE CARGA / SISCOMEX / SISCARGA
--------------------------------------------------------------------------------
Simular o acompanhamento automático de cargas.

Fluxo desejado:
1. Sistema pega a lista de CNPJs cadastrados
2. Consulta informações no Siscomex/Siscarga
3. Captura atualizações de cada carga
4. Salva um snapshot diário
5. Compara o snapshot de hoje com o de ontem
6. Identifica mudanças
7. Gera relatório automático
8. Envia para WhatsApp/e-mail/grupo interno

No front, criar:
- lista de snapshots diários
- comparação "ontem vs hoje"
- mudanças detectadas
- status da carga
- data da última consulta
- relatório automático gerado por IA
- botão visual "gerar relatório"
- botão visual "enviar para grupo interno"

Não precisa integrar de verdade. Usar mocks.
